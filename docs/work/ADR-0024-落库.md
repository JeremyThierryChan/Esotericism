> 状态：**✅ 已实现并上线**

> 代码：`apps/preview/src/store.ts`（存储）· `packages/domain/src/layer4/analysis.ts`（分析）· `apps/preview/src/data-panel.ts`（面板）

---

## 一、为什么需要它

ADR-0008 **step 4** 的验收标准是「拿到 Mastery 向量与混淆对数据」。
但在这一步之前，**采集是零** —— 积分与作答只存在内存里，**刷新即丢**。
于是「自己玩两周攒数据」这句话没有落点：玩完什么都不剩。

落库把这句空话变成了：**作答 → 证据 → 积分 → 掌握度快照 一次事务写入 + 可视化 + 导出**。

---

## 二、选型：为什么是 IndexedDB，不是 SQLite-WASM

ADR-0002 定的是 PostgreSQL（最终形态）。但在**预览站（静态托管）**上：

> sqlite-wasm 的 OPFS 持久化模式需要 `SharedArrayBuffer` → 需要 **COOP/COEP 响应头**
> → **GitHub Pages 不能设置自定义响应头**。

**这是死路，不是偏好。** 所以选浏览器原生的 IndexedDB：零依赖、无需任何响应头、静态站直接可用。

**将来怎么办**：真实使用仍需服务端 + PostgreSQL。表结构**按可平移设计**
（字段与 `docs/待采集数据.md` §五 一一对应），届时搬过去即可。

---

## 三、落实采集规格的三条硬约束

| 约束 | 落实方式 |
|---|---|
| ① `attempt` **只追加** | 判分结果可重算，但「用户当时选了什么」不可重建 |
| ② `evidence` 是掌握度**唯一入口** | 不能由「看完了」「连续签到」产生（V0.1 §9.2） |
| ③ 预设匹配**写入时算好** | 事后 join 需要内容库版本，**而内容库会变** |

**连带推论：分析所需字段必须冗余存进 `Attempt`。**
新增 `template_id` / `exercise_kind` / `correct_label` —— 内容库会变（题目会被改、模板会被回调），
不冗余就不可复现。宁可冗余。

## 四、分析层（`packages/domain/src/layer4/analysis.ts`）

纯函数，15 条测试。**时间由参数传入**，所以合成数据就能把每条判定测到，不必等两周真实数据。

| 函数 | 算什么 | 校准什么 |
|---|---|---|
| `exerciseStats` | 首次答对 vs 多次答对（分开展示） | 题目难度 |
| `latencyByKind` | 按题型的耗时中位数 / p90 | **认知负荷权重（现为 1/2/3/4/5，是我拍的）** |
| `computeConfusionPairs` | 实测混淆对 vs 预设 | **V0.1 §9.3 三分支** |
| `forgettingCurve` | 按「距上次作答」间隔分桶 | SRS 间隔 |
| `scoreStats` | 总额 / 零分占比 / 单次最高 | 给分是否合理、反刷分触发频率 |

### 三分支判断（最值钱的一环）

| 判定 | 含义 | 动作 |
|---|---|---|
| `expected` | 用户混淆了**预设的**一对 | 教学正常现象 → 触发对比练习 |
| `unexpected` | 混淆了**未预设的**一对 | ⚠️ **内容或教学有问题** → 内容质检 |
| `cross_system` | 混淆的两端分属不同形式系统 | 过度迁移 → 触发反向练习 |

**匹配方式**：预设端点是节点 id，作答记的是选项标签 —— 用 `nameOf` 把端点翻成展示名再比，
不依赖标签与 id 的命名约定。

## 五、数据面板（页面上可见）

显示「攒了多少 / 每题首答率 / 耗时分布 / 混淆对三分支 / 遗忘曲线」，并**明确写出能/不能得出什么**：

> **能**：校准一批我拍的数值，以及验证我预测的 4 对八卦镜像对是否真的会混。
> **不能**：证明「这套学习方法有效」—— 我是出题人，知道所有答案与设计意图（观察者偏差）。
> **自用数据只能校准仪器，不能证明仪器测的东西有意义。**

**导出 JSON 是必需功能，不是可选项** —— 不导出就等于数据只在这台机器的浏览器里。

## 六、两个被真实场景验证到的细节

1. **存储降级**：隐私模式 / 无 `indexedDB` 环境 → 降级为内存，并**明确提示「本次数据不会保存」**
   （不让人以为攒到了）。冒烟测试的 DOM 替身里**正好没有 `indexedDB`**，所以这条路径被真实验证。
2. **存储失败不阻塞作答**：写入失败的提示插在结果区，学习流程继续。
