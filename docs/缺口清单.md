## G. 优先级建议（含依赖关系）

```
① 人工签字（D1）──────── 唯一只有你能做的；解锁 D2、并让后续内容有合法归属
   │
② 落库（C2-1）────────── 解锁 E6 → step 4「自用两周」才可能拿到数据
   │                     也解锁 C2-4（账号）、C2-9（混淆对采集）
   ├─→ ③ 内容流水线工具（C2-2）── ADR-0008 指定的「第一个要写的 UI」
   │
   ├─→ ④ V0.4 课程系统（B2）── 解锁 A7（97 题目前平铺）
   │      └─→ ⑤ V0.5 练习系统（B3）── 解锁 A8（只有 1 种题型）
   │
   └─→ ⑥ V0.6 掌握度与复习（B4）── 依赖 E6 的数据
   
文献线（与代码线并行，卡点是文献不是代码）：
   ⑦ 取《增删卜易》/《卜筮正宗》正文 → 解锁 A1 纳甲 → A2 六亲 → A3 旺衰 → A4 冲合
   ⑧ 取 *Book T* 原条目 → 加强 D5（塔罗↔占星）
```

### 如果只能做一件事

**② 落库。** 理由：现在 97 题闭环跑得通，但**玩完什么都不剩** ——
step 4 的全部目的是「自己当用户玩两周，拿到 Mastery 向量与混淆对数据」，
而没有落库就没有数据，step 4 无法完成，V0.6 也没有校准依据。这是当前**最具杠杆的单点**。

### 如果只能等你做一件事

**① 签字。** 内容 100% 是 `draft`，这既挡着可见性策略收紧（D2），
也让「后加的内容该往哪个状态放」没有参照 —— 越晚签，欠账越多。
